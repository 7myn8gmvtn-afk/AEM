# Nova Pro Max v3

Protótipo pessoal da Nova com identidade formal, educada e profissional por padrão.

## Identidade e linguagem
- Saudação padrão: “Olá. Como posso ajudá-lo?”
- Linguagem padrão: português brasileiro formal e natural.
- Regras de ortografia, acentuação, pontuação, concordância e regência foram incorporadas como orientação do protótipo.
- O usuário pode solicitar modo informal ou voltar ao modo formal.
- A Nova deve declarar incerteza em vez de inventar informações.

## Funções do protótipo
- Abertura de apps/sites conhecidos.
- Calculadora.
- Memória local.
- Anotações.
- Registro e resumo de gastos locais.
- Histórico.
- Reconhecimento de voz quando suportado pelo navegador.

## Importante sobre conhecimento
Este é um protótipo web estático. Colocar regras e dados dentro do JavaScript não transforma o protótipo em um modelo de IA com conhecimento universal. Para responder perguntas gerais com profundidade e atualização, a Nova precisará futuramente de um motor de IA/LLM e, quando necessário, de fontes de consulta. Nenhum sistema deve prometer “zero erros”.

## Privacidade
Memória, notas, gastos e histórico deste protótipo ficam no armazenamento local do navegador. Ele não acessa contas bancárias nem movimenta dinheiro.
